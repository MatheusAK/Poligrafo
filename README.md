# Teste do Polígrafo

Este projeto é uma atividade escolar desenvolvida com HTML, CSS e JavaScript para simular um teste de polígrafo em formato interativo.

## O que é o projeto?

O objetivo do site é apresentar uma sequência de perguntas sobre comportamento e situações suspeitas, permitindo que o usuário responda "Sim" ou "Não". Ao final, o sistema calcula a quantidade de respostas afirmativas e exibe um resultado, como "Inocente", "Suspeito", "Cúmplice" ou "Altamente Suspeito".

A ideia da atividade é praticar a criação de interfaces web simples e a lógica de interação com o usuário, usando uma abordagem divertida e educativa.

## Funcionalidades

- Exibição de perguntas em sequência
- Seleção de respostas com botões de rádio
- Barra de progresso que mostra o avanço do questionário
- Validação para impedir envio antes de responder todas as perguntas
- Geração de resultado final com base nas respostas marcadas

## Competências treinadas

Durante o desenvolvimento deste projeto, foram praticadas e exercitadas as seguintes habilidades:

- Estruturação de páginas com HTML
- Estilização visual com CSS
- Manipulação de elementos da página com JavaScript
- Trabalho com eventos e interações do usuário
- Lógica condicional para tomada de decisões
- Organização e uso de arrays para armazenar perguntas
- Desenvolvimento de interfaces front-end simples e funcionais

## Como executar

1. Abra a pasta do projeto
2. Localize o arquivo `poligrafo.html`
3. Abra-o em um navegador web

Pronto! O questionário será carregado e poderá ser utilizado normalmente.
